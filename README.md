# Tickbyte

<img width="424" height="251" alt="image" src="https://github.com/user-attachments/assets/cf46218a-7a20-4459-b82f-4fa84bdf0239" />

**Tickbyte** is a lightweight macOS menu bar application that displays real-time crypto prices using the Binance WebSocket API.

## Features

- Real-time Crypto Prices
- Multi-Crypto Support
- 24h Price Percentage Change

## Installation

1. Download and unzip **`Tickbyte.zip`** from the [latest release](https://github.com/AttackOnMorty/tickbyte/releases).
2. Move **Tickbyte** to your **Applications** folder.
3. Open the app. macOS will likely complain that this app is "unverified."
   - Go to **System Preferences** → **Security & Privacy**.
   - Under the **Security** section, find the warning about **Tickbyte**.
   - Click **"Open Anyway"** to trust the app.
