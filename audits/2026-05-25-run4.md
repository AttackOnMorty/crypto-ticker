### Performance

#### F1 · ⚪ Low — Per-item menu attributes (paragraph style, tab stops, font) are rebuilt on every refresh

**Status:** 🆕 new · **Effort:** Quick win

**Impact:** While the menu is open, every incoming trade reposts `.priceUpdated` → `refreshMenuItems` rebuilds all 7 rows, and each row reallocates an identical `NSMutableParagraphStyle`, 5 `NSTextTab`s, and re-runs an `NSFont(name:size:)` lookup. None of this varies by currency or by trade, so it is wasted allocation on the open-menu path. Not user-visible (AppKit's own menu layout dominates), but it is the exact cost class the project already chose to eliminate for `NumberFormatter`.

**Fix:** Hoist the base attributes (paragraph style with tab stops + font) into a stored `static let` / lazy property computed once, like `PriceFormatter`'s reused formatters; `attributedMenuTitle` then only builds the per-row string and applies the two colour ranges.

<details><summary>Technical details</summary>

**Where:** `AppDelegate.swift` — `attributedMenuTitle` (lines 135–142), reached via `configureMenuItem` (line 118) ← `refreshMenuItems` (loops `availableCurrencies`, 7) ← `dataDidChange` (line 213, fires on every `.priceUpdated` while `isMenuVisible`).

**Evidence:** Per refresh while the menu is open: 7 × (`NSMutableParagraphStyle` + `Self.menuTabStops.map { NSTextTab(...) }` = 5 tab objects + `NSFont(name:size:)` lookup) = 7 paragraph styles, 35 `NSTextTab`s, 7 font lookups — all identical every call. `.priceUpdated` posts once per trade message per symbol (`handleIncomingData`), so this repeats several times/sec on an open menu. Bounded to the open-menu window, hence Low.

**Suggested fix:**

```swift
// Computed once; the attributes never change between rows or trades.
private static let menuBaseAttributes: [NSAttributedString.Key: Any] = {
    let paragraphStyle = NSMutableParagraphStyle()
    paragraphStyle.tabStops = menuTabStops.map { NSTextTab(textAlignment: .left, location: $0, options: [:]) }
    let font = NSFont(name: AppConfiguration.UI.menuFont, size: AppConfiguration.UI.menuFontSize)
        ?? NSFont.monospacedSystemFont(ofSize: AppConfiguration.UI.menuFontSize, weight: .regular)
    return [.font: font, .paragraphStyle: paragraphStyle]
}()
// attributedMenuTitle then: NSMutableAttributedString(string: row.text, attributes: Self.menuBaseAttributes)
```
</details>
